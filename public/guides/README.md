# Guías ONDA (imágenes / infografías)

Colocá aquí imágenes para que el bot las envíe cuando el modelo indique `[ONDA_GUIA:nombre]`.

**Nombres de archivo:** `estafa.png`, `phishing.png`, `deepfake.png`, `criterio.png`, `instituciones.png`, `derechos.png`, `actividad.png` (o `.jpg`).

- **Chat web:** se muestran en la burbuja del bot.
- **WhatsApp:** se envían como mensaje de imagen después del texto.

Si no existe el archivo, solo se envía el texto de la respuesta.
